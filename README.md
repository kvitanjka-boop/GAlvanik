# Galvanik

Jojos Arbeitsmappe zur Galvanoformung (Verkupfern von Blättern und Naturformen, Schmuck, Verkauf).

- **etappen/** – Etappen 00 bis 25: vom Galvanikbad bis zu Preisen, Verkauf, Versilbern und Vergolden. Start: `etappen/00_Uebersicht.md`
- **electroforming-recherche/** – Wissensbasis, Leitfaden, eigene Erfahrungen, Ideen
- **galvanik-app/** – Galvanik-Simulator und 3D-Bad-App (Quelltext und Programm)
